# zomato-data-analysis-python
Exploratory Data Analysis of Zomato restaurant data using Python, Pandas, Matplotlib and Seaborn.
# Zomato Data Analysis Using Python

## 📌 Project Overview

This project analyzes Zomato restaurant data using Python to identify
restaurant trends, customer preferences, ratings, votes, spending patterns,
and online/offline ordering behavior.

## 🎯 Business Objective

The objective of this project is to analyze customer ordering behavior
and restaurant performance and generate useful business insights for
Zomato.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset

The dataset contains information about restaurants, restaurant types,
ratings, votes, online ordering, approximate cost and other attributes.

## 🔍 Analysis Performed

1. Restaurant type analysis
2. Votes by restaurant type
3. Rating distribution
4. Average spending analysis
5. Online vs offline rating analysis
6. Offline order analysis
7. Correlation and heatmap analysis

## 📊 Key Questions

- What type of restaurant do the majority of customers order from?
- How many votes has each type of restaurant received?
- What ratings have most restaurants received?
- What is the average spending on each order?
- Which mode received the maximum rating?
- Which restaurant type received more offline orders?

## 📈 Key Insights

1. Majority of the restaurant falls in dinning category
2. Dinning restaurants has received maximum votes
3. The majority restaurants received ratings from 3.5 to 4
4. Majority of couples prefer restaurants with an approximate cost of Rs.300
5. Offline order received lower rating in comparison to online order
6. Dining restaurants primarily accepts offline orders, where cafes primarily receive online orders. This suggests that clients prefer to place orders in person at restaurants, but prefer online ordering at cafes.

## 💡 Business Recommendations

1. Zomato can focus promotional campaigns and partnerships on dining restaurants because they have the highest presence and customer votes.

2. Zomato can introduce special offers and loyalty programs for dining restaurants to improve customer engagement and encourage more orders.

3. Since couples commonly prefer restaurants costing around ₹300, Zomato can provide targeted couple deals and combo offers within this price range.

4. Zomato can work with restaurants to improve offline customer experience, as offline orders receive lower ratings compared with online orders.

5. Zomato can develop category-specific marketing strategies, such as promoting online-order discounts for cafes and offers that encourage greater platform engagement with dining restaurants.
